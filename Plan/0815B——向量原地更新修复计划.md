# 向量原地更新（update）修复计划

> 目标：解决「节点 content 更新后，向量库仍存旧向量」的问题，使人工干预与 DBA 自动维护的 update 操作能正确同步向量。

---

## 一、背景与问题

当前 [VectorStore.add_memories](file:///c:/Users/makot/Desktop/Ariadne/dba_pipeline/embedding/store.py#L123-L166) 是**新增语义**：

- [store.py#L131](file:///c:/Users/makot/Desktop/Ariadne/dba_pipeline/embedding/store.py#L131) 只对 `new_ids`（不在 `_content_vectors` 里的 id）重算向量；
- 对已存在的 id 取旧向量，再 `store.add_embeddings` **追加**到 FAISS 索引。

因此 update 一个已存在节点时：`_content_vectors` 缓存不变（旧向量），FAISS 索引出现「旧向量+旧内容」「旧向量+新内容」两条记录。

**受影响写方**：`GraphBuilder._update_node`、`DBAServer.intervene.update_node`。
**受影响读方**：`PurposeDrivenRetriever`（种子/候选向量）、`GraphBuilder._find_duplicate`（去重）、`MemoryDBA._build_context`（DBA 上下文检索）。

---

## 二、方案设计

采用 **「权威映射 + 全量重建」**：

1. `VectorStore` 额外维护 `_contents: {memory_id: content}`，与 `_content_vectors: {memory_id: vector}` 同步，作为权威数据源。
2. 新增 `update_memories(memory_ids, contents)` 方法：对给定 id 重算向量 → 更新两个映射 → **全量重建 FAISS 索引**。
3. 新增 `_rebuild_index()`：从两个映射一次性 `FAISS.from_embeddings` 重建，保证索引与映射一致。
4. 新增/更新的调用方分别走 `add_memories`（增量）与 `update_memories`（重建）。

**为什么全量重建而非 IndexIDMap 原地更新**：
- 项目规模小（README 称 216 节点），`FAISS.from_embeddings` 重建 216 条几乎瞬时；
- update 是低频操作，全量重建的 O(N) 成本可忽略；
- 避免操作 FAISS 底层 `IndexIDMap`/`remove_ids` 的复杂度与 LangChain 封装兼容性风险。

> 备选方案（若未来图规模增长到万级）：改用 `faiss.IndexIDMap` + 固定整数 id + `remove_ids`/`add_with_ids` 做真原地更新，本计划不采用。

## 四、验收标准

1. 调用 `update_memories(id, 新content)` 后，`_content_vectors[id]` 变为新向量，`_contents[id]` 变为新内容。
2. FAISS 索引中该 id 只存在一条记录，且向量为新向量（不再膨胀/错配）。
3. `GraphBuilder._update_node` 与 `intervene.update_node` 更新后，P 链路检索能命中更新后的语义内容。
4. `save` → `load` 往返后，`_contents` 与 `_content_vectors` 完整一致。
5. 现有 26 项测试全通过；新增 update 相关测试覆盖「向量重算」与「索引重建」。

---

## 五、风险与权衡

- **旧 checkpoint 兼容**：历史 `content_vectors.npz` 无 `contents` 字段，`load` 后 `_contents` 为空。此时若触发 `update_memories`，全量重建会缺其他节点的 content。
  - 缓解：`load` 检测到缺 contents 时，从 FAISS `docstore` 补全；或文档注明「旧检查点需先重新灌入」。
- **重建性能**：每次 update 全量重建 O(N)，万级节点前需切换 IndexIDMap 方案。
- **metadatas**：重建时仅保留 `memory_id`，其余自定义 metadata 会丢失（当前无实际使用，可接受）。
